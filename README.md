# 🏷️ LabelWhisper — The Gentle Art of Label Printing

[!["Buy Me A Coffee"](https://www.buymeacoffee.com/assets/img/custom_images/orange_img.png)](https://buymeacoffee.com/spreed)

## Overview
In a world bloated with software noise and cluttered UIs, *LabelWhisper* was born as a breath of calm.  
A lightweight, bloat-free C# Avalonia application dedicated solely to the art of printing labels — quickly, beautifully, and with precision.

## 🌿 Why LabelWhisper?

Because sometimes, all you need is a whisper — not a scream.

LabelWhisper speaks gently to your label printer, offering:
- 🖨️ **Effortless Label Printing**: Point, click, print.
- 🧭 **Minimal UI**: No distractions, just labels.
- ⚙️ **Cross-platform**: Thanks to Avalonia, it dances across Windows, macOS, and Linux.
- 🚫 **No Bloatware**: Pure functionality. No ads. No nonsense.
- 🎯 **Precision Built**: For thermal printers, barcode labels, shipping slips — you name it.

## ✨ Features

- Simple interface with intuitive flow
- Printer selection by using the printers name
- Quick preview
- Compatible with ***all*** printers
